# 华为风格 PPTX 规范 v0.9

本规范用于外网近似实现,真实华为 CI、字体和母版需进入内网后校准。所有可配置值集中在 `backend/app/rendering/themes/hw_theme.json`,渲染器和 lint 不应硬编码颜色、字体、字号、页边距或页脚文案。

## Tokens

- 主色: `#C7000B`,外网近似华为红。
- 字体: 外网优先微软雅黑,内网目标 HarmonyOS Sans SC,西文 Arial。
- 页面: 16:9,13.333 x 7.5 英寸,四边距 0.6 英寸。
- 网格: 12 栏,8pt baseline,文本框左右边界需吸附到网格。
- 页脚: 左侧密级,右侧页码,默认密级 `HUAWEI CONFIDENTIAL`。
- 禁用: 动画、切换、白名单外字体、夸张阴影/渐变、真实 logo。

## 待内网校准

- 官方字体文件与实际 fallback 顺序。
- 官方红色、灰阶与对比度要求。
- PPT 母版中页脚、标题区和 logo 占位的精确坐标。
