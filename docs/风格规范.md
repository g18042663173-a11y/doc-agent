# 华为风格 PPTX 规范 v1.1

本规范已经按 `SOURCE_FILE_SPEC.md` 对真实源 PPTX 的 XML 实测值校准。早期 PPTskill 文档值与实测冲突时,以本页和 `backend/app/rendering/themes/hw_theme.json` 为准。

## 来源优先级

1. 真实源 PPTX XML 实测规格 `SOURCE_FILE_SPEC.md`。
2. 华为公开设计规范,仅补充原则。
3. 业务 PPT 照片,只用于版式方向,不用于反推精确颜色和字体。

评审决策见 `docs/reviews/主题校准评审记录.md`。

## 颜色

- accent1/主红:`#C7000B`
- accent2 浅红:`#F85948`
- accent3 橙:`#ED6D00`
- accent4 黄:`#FCC800`
- accent5 绿:`#61B230`
- accent6 青:`#30B5C5`
- 主文字:`#1D1D1A`;次要文字:`#666666`
- 白底:`#FFFFFF`;灰底/边框:`#DDDDDD`;表格斑马纹:`#F5F5F5`

`#C00000` 是早期规范值,不再作为当前主题主红。

## 字体与字号

- 中文:微软雅黑
- 英文:Arial
- 字号层级:14/12/11/10/9/8pt
- 正文行距:1.3
- 单页字号种类不超过 3

HarmonyOS 字体仍需内网提供并在 Windows 目标环境校准;当前白名单不虚构未安装字体。

## 页面与网格

- 页面:13.34 x 7.50 英寸,16:9
- 页边距:左/右 0.57 英寸,上 0.29 英寸,下 0.50 英寸
- 网格:12 栏,8pt baseline
- 页脚:左侧 `Security Level: X`,底部居中版权,右侧 `当前/总页数`
- Logo:右上角占位,不内置真实商标文件

## 表格与图表

- 表头主红、白字、11pt 加粗;数据行 10pt;表格边框 1pt `#DDDDDD`
- chart 使用 python-pptx 原生可编辑图表;坐标轴/图例/数据标签 9pt
- 阈值线使用主红虚线和 8pt 标签;侧栏按主题 token 留出右边距
- image layout 当前允许明确占位降级,不得伪装成真实图片

## 禁止项与验收

- 禁止动画、切换、白名单外字体、夸张阴影/渐变和把主要内容图片化
- renderer 与 lint 从同一 `hw_theme.json` 读取 token
- 自动 lint 只证明硬指标;Windows 目标字体视觉终审仍由人完成
