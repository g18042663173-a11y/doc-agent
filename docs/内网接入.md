# 内网黄区接入说明

本项目已交付确定性本地流水线、OpenAI-compatible NGA adapter、浏览器工作台和 Windows
WPF 原生客户端。进入黄区后只配置 generator；只有内网明确提供不同协议或官方渲染 Skill
时才新增 adapter，不改 IR、parser、prompt、lint 或确定性 renderer。

## 两个替换点

1. `backend/app/generators/nga.py`

   已实现 `generate(prompt: str, *, target: "word_ir" | "deck_ir" | "analysis") -> str`，
   按 OpenAI-compatible Chat Completions 调用内网 NGA。默认 `/v1/chat/completions`、Bearer
   Token、`temperature=0`、非流式；只重试超时、429、502、503、504。若实际协议不同，
   新增独立 adapter，不在现有 renderer 中拼接模型输出。

2. 华为官方渲染 Skill

   若黄区提供华为官方渲染 Skill,以 DeckIR v2.0 作为输入契约接入。现有 `backend/app/rendering/pptx_renderer.py` 保留为回退开关,不可改变上游 IR、prompt、parser 或 lint 契约。存量 1.4-1.9 输入只在现有校验入口内存迁移,官方 Skill 不得自行猜测旧字段。

## 环境变量

- `NGA_BASE_URL`: 内网模型网关地址。
- `NGA_TOKEN`: 内网模型网关令牌。
- `NGA_TIMEOUT_SECONDS`: 可选,默认由实现层设置。
- `NGA_MAX_RETRIES`: 可选,默认由实现层设置。
- `NGA_ENDPOINT_PATH`: 可选，默认 `/v1/chat/completions`。
- `NGA_MODEL`: CLI/环境变量模式下必填。
- `NGA_VERIFY_TLS`、`NGA_CA_BUNDLE`、`NGA_ALLOW_INSECURE_HTTP`: TLS 与自定义 CA。

原生客户端不把 Token 写入环境变量或 JSON。它使用 Windows Credential Manager 目标
`HuaweiDocumentGenerator/NGA`；`%LOCALAPPDATA%\HuaweiDocumentGenerator\settings.json`
只保存非敏感配置。用户必须先测试再启用，启用失败后生成保持阻断，不能静默回退 Stub。

## 不动清单

进入黄区后默认不改:

- `backend/app/ir/`: IR pydantic 模型、Schema、错误码与剥壳校验。
- `backend/app/parsers/`: md / docx / xlsx / pptx 输入解析。
- `backend/app/prompting/`: Prompt 模板与截断策略。
- `backend/app/lint/`: PPTX 合规检查规则与报告结构。
- `backend/app/cli/`: parse / prompt / render / check 命令签名。
- `samples/ir/`: 正反样例与回归语料。
- `backend/app/assets/` 与 `backend/app/visual/`: 图片安全清单、VisualPlan 和审计契约。

## 离线安装

在可联网机器上为 Windows Python 3.12 构建 wheelhouse:

```bash
python scripts/make_wheelhouse.py --platform win_amd64 --python-version 3.12 --output wheelhouse
python scripts/hash_wheelhouse.py
```

拷贝项目和 `wheelhouse/` 到黄区 Windows 机器后:

```powershell
.\bootstrap_windows.ps1
.\verify.ps1
```

`bootstrap_windows.ps1` 内部固定执行
`.venv\Scripts\python.exe -m pip install --no-index --find-links wheelhouse --require-hashes -r requirements-win312.lock`,
不会安装到系统 Python。

下载清单和 SHA-256 见 `docs/wheelhouse-win312-manifest.json`。该清单证明 wheel 来源和内容可审计,不代表已在 Windows 断网安装;真机结果必须另行记录。
`graphviz-0.21-py3-none-any.whl` 只提供 Python 调用层;Graphviz Windows 运行时需在联网环境
单独下载并审计后放入 `tools/graphviz/`,不能把 wheelhouse 绿灯当作 `dot.exe` 已部署。
环境选择结果、Graphviz 版本/SHA-256 和 fallback 状态写入 `output/environment_report.json`。

## 内网自测顺序

1. 断网安装依赖,先跑 stub 全链路:

   ```powershell
   python scripts/verify.py
   ```

2. 用 `samples/input/quarterly_report.md` 跑 Word 和 Deck demo,确认本地渲染、合规检查和报告都正常。
3. 用本地 PNG/JPEG/WebP 跑 `app.cli.assets` 和带 `--asset-manifest` 的 Deck，确认图片哈希、使用审计及 `A001-A006` 错误码。
4. 在 WPF“设置 > NGA”配置地址、模型、Token 和 CA，执行“测试连接”后再启用；或为 CLI
   配置 `NGA_BASE_URL/NGA_MODEL/NGA_TOKEN`。先做单页 WordIR/DeckIR 冒烟并核对 E010-E014。
5. 先用 `scripts/analyze.py` 检查实测数字与三档建议,再用 `scripts/generate.py --depth 详细` 验证分批 DeckIR;确认 `generation_manifest.json` 中没有未修复的截断错误。
6. 若接入华为官方渲染 Skill,先以同一份 DeckIR 对比官方输出与本地回退输出。
7. 记录 Python 版本、Windows 版本、安装命令、verify 输出和打开 Word / PowerPoint 的截图。

## 安全约定

- NGA token 不写入 JSON、日志、任务目录或失败报告；WPF 只存 Windows Credential Manager。
- 默认不落盘原始敏感 Prompt;如需运行记录,先由导师确认保存范围。
- 示例数据必须脱敏后再进入 `samples/input/real/`。
