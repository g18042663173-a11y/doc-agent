# 内网黄区接入说明

本项目外网阶段只交付确定性本地流水线。进入黄区后,原则上只替换两处:generator 与华为官方渲染 Skill 对接层。

## 两个替换点

1. `backend/app/generators/nga.py`

   实现 `generate(prompt: str, *, target: "word_ir" | "deck_ir" | "analysis") -> str`,负责调用内网 NGA。`analysis` 只返回 prompt 定义的独立页数建议/大纲 JSON,不属于 IR 契约。鉴权、超时、重试和日志脱敏都放在这一层。密钥只允许走环境变量,不得写入配置文件或运行记录。

2. 华为官方渲染 Skill

   若黄区提供华为官方渲染 Skill,以 DeckIR v1.6 作为输入契约接入。现有 `backend/app/rendering/pptx_renderer.py` 保留为回退开关,不可改变上游 IR、prompt、parser 或 lint 契约。

## 环境变量

- `NGA_BASE_URL`: 内网模型网关地址。
- `NGA_TOKEN`: 内网模型网关令牌。
- `NGA_TIMEOUT_SECONDS`: 可选,默认由实现层设置。
- `NGA_MAX_RETRIES`: 可选,默认由实现层设置。

## 不动清单

进入黄区后默认不改:

- `backend/app/ir/`: IR pydantic 模型、Schema、错误码与剥壳校验。
- `backend/app/parsers/`: md / docx / xlsx / pptx 输入解析。
- `backend/app/prompting/`: Prompt 模板与截断策略。
- `backend/app/lint/`: PPTX 合规检查规则与报告结构。
- `backend/app/cli/`: parse / prompt / render / check 命令签名。
- `samples/ir/`: 正反样例与回归语料。

## 离线安装

在可联网机器上为 Windows Python 3.12 构建 wheelhouse:

```bash
python scripts/make_wheelhouse.py --platform win_amd64 --python-version 3.12 --output wheelhouse
python scripts/hash_wheelhouse.py
```

拷贝项目和 `wheelhouse/` 到黄区 Windows 机器后:

```powershell
python -m pip install --no-index --find-links wheelhouse --require-hashes -r requirements-win312.lock
.\verify.ps1
```

下载清单和 SHA-256 见 `docs/wheelhouse-win312-manifest.json`。该清单证明 wheel 来源和内容可审计,不代表已在 Windows 断网安装;真机结果必须另行记录。

## 内网自测顺序

1. 断网安装依赖,先跑 stub 全链路:

   ```powershell
   python scripts/verify.py
   ```

2. 用 `samples/input/quarterly_report.md` 跑 Word 和 Deck demo,确认本地渲染、合规检查和报告都正常。
3. 配置 `NGA_BASE_URL` 与 `NGA_TOKEN`,只切换 `generators/nga.py` 做单页冒烟。
4. 先用 `scripts/analyze.py` 检查实测数字与三档建议,再用 `scripts/generate.py --depth 详细` 验证分批 DeckIR;确认 `generation_manifest.json` 中没有未修复的截断错误。
5. 若接入华为官方渲染 Skill,先以同一份 DeckIR 对比官方输出与本地回退输出。
6. 记录 Python 版本、Windows 版本、安装命令、verify 输出和打开 Word / PowerPoint 的截图。

## 安全约定

- 不保存 NGA token。
- 默认不落盘原始敏感 Prompt;如需运行记录,先由导师确认保存范围。
- 示例数据必须脱敏后再进入 `samples/input/real/`。
