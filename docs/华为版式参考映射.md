- 本文只吸收公开版式分类和视觉检查经验，不复制 HTML、CSS、JavaScript、模板或素材。
- 外部 H01-H42 不是 DeckIR layout 名称，模型和代码不得输出这些编号。
- 渲染仍使用 python-pptx 原生对象；主题真值仍以 `SOURCE_FILE_SPEC` 和 `hw_theme.json` 为准。

## 映射结论

| 外部页面类型 | 参考编号 | DeckIR 处理 | 结论 |
|---|---|---|---|
| 封面、目录、章节、收束 | H01-H03、H10 | `cover`、`agenda`、`section`、`conclusion` | 直接承接 |
| 观点、前言、长说明 | H04、H11 | `title_bullets` | 直接承接，内容超量时人工拆页 |
| 并列能力、图标矩阵、商业模式 | H05、H20、H31 | `cards` | 直接或近似承接 |
| 数据条、KPI、市场规模 | H07、H15、H22、H28-H30 | `chart.orientation=horizontal` 或 `cards.variant=kpi` | DeckIR v2.0 直接承接数据条与 KPI；营销装饰不进入契约 |
| 图片证据、人物、案例、图文报道 | H09、H12-H14、H19、H25、H36 | `image`、`image_text` 或 `image_grid` | 由 AssetManifest 提供 1-4 张真实图片，保持来源和裁切审计 |
| 趋势和性能分析 | H16 | `chart` | bar/line/pie/scatter 及双量纲 combo；combo 为两张对齐的原生图表 |
| 中心辐射、闭环、协同机制 | H17、H23、H32、H37-H41 | `architecture_diagram` 或 `infographic.cycle` | 关系图与闭环图均保持原生可编辑 |
| 方案对比、问题概览、定价、SWOT、前后对比 | H26、H27、H33、H34、H42 | `table`、`two_column` 或 `cards` | 直接或近似承接 |
| 流程箭头 | H08 | `process_flow` | DeckIR v1.5 新增 |
| 时间线、路线图 | H06、H18、H24 | `timeline` | DeckIR v1.5 新增 |
| 地图与区域点位 | H21 | 暂无 | 暂缓，依赖地图数据和可编辑地图方案 |
| 精确甘特图 | H35 | 暂无 | 暂缓，不能用简化时间线冒充 |

## 选版规则

1. 先确定页面要表达的关系，再选择版式，不为追求多样性强行换版式。
2. 标题写判断；每页只承载一个判断，核心内容点控制在 1-3 个。
3. 7 页以上才默认加入目录；10 页以上且原文存在至少两个一级章节时才加入章节页。
4. 有足够内容关系时再增加版式变化；正文不得连续 3 页使用同一版式。
5. 编号步骤或明确流程条目使用 `process_flow`；至少两个不同时间标签使用 `timeline`；存在分支或任意连接关系使用 `architecture_diagram`。
6. 精确 Gantt 和地图等当前不能真实表达的页面必须明确暂缓，不用近似图冒充成品；组合图只在主次系列量纲不同且有比较价值时使用。

## 视觉检查吸收项

- 品牌位、标题轴和页脚位置稳定。
- 同级卡片、步骤、里程碑尽量等宽等高。
- 普通正文页以白/浅灰为底，红色只作标题、编号、箭头和关键数据锚点。
- 内容不得进入页脚安全区；缩到主题最小字号后仍放不下必须给 Warning。
- 所有自动检查基于 PPTX 实际形状几何，不能采信 renderer 自报坐标。
