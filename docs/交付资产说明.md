# 交付资产说明

本目录说明 P1 交付资产的来源、复现命令和验证边界。核心实现与 IR Schema 不由这些脚本改写。

## 固定样例

- `samples/input/需求说明.docx`:两级标题、列表、表格和文本框降级标记。
- `samples/input/销售台账.xlsx`:3 个 sheet、公式、跨行/跨列合并单元格。
- `samples/input/项目汇报.pptx`:8 页,含表格、原生图表、演讲备注和空白页。
- `samples/input/parser_matrix/manifest.json`:md/docx/xlsx/pptx 各 normal、empty、corrupt、large、degraded 五类。

固定样例和结构基线由下列命令生成:

```bash
PYTHONPATH=backend python scripts/build_delivery_assets.py
```

该命令只在明确更新 golden 时执行。`pytest` 和 `verify.py` 只读比较 `samples/expected/`,不会在测试前覆盖基线。

## IR 与 lint 反例

- `samples/ir/deck_invalid_manifest.json`:D001-D006 每码一个稳定反例。
- `samples/ir/deck_lint_violation.json`:先渲染为合法 PPTX 的输入 IR。
- `samples/ir/deck_lint_violation.inject.json`:PPTX 层违规注入操作和期望 HW 码。

生成可演示违规 PPTX 与双格式报告:

```bash
PYTHONPATH=backend python scripts/make_lint_violation.py
```

## Expected 与结果样例

- `samples/expected/`:解析、DOCX、Deck、lint 的结构性事实;不比较易变 Office 二进制字节。
- `samples/expected/manifest.json`:每份 expected JSON 的 SHA-256。
- `samples/output/word/`:3 个官方 WordIR 的可编辑 DOCX 结果。
- `samples/output/deck/`:全版式 Deck 与 lint 违规 PPTX/报告。

## Windows wheelhouse

```bash
python scripts/make_wheelhouse.py --platform win_amd64 --python-version 3.12
python scripts/hash_wheelhouse.py
```

结果:

- `docs/wheelhouse-win312-manifest.json`:真实下载 wheel 的文件名、字节数和 SHA-256。
- `requirements-win312.lock`:直接依赖和传递依赖的精确版本/hash。
- `wheelhouse/`:本地下载目录,按 `.gitignore` 不入库。

Mac 上下载并计算 hash 不等于 Windows 断网安装通过。真机安装与 `verify.ps1` 仍按 `docs/验收手册.md` 人工执行。
