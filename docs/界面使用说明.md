# 界面使用说明

## 启动

```bash
PYTHONPATH=backend python3 -m app.web --host 127.0.0.1 --port 5055
```

默认工作目录是 `output/web/`,每次生成会写入一个独立 job 目录,包含输入快照、`document_ir.json`、`prompt.txt`、生成的 IR、产物和检查报告。

## 三步使用

1. 在“输入”区域上传 `.md` / `.docx` / `.xlsx` / `.pptx`,或直接填写主题文本。
2. 在“生成”区域选择 `Word` 或 `PPTX`,点击“生成”。
3. 在“合规检查报告”区域查看 Error / Warning / Info 分级结果,点击“下载产物”取得 `.docx` 或 `.pptx`。

若生成的 IR 校验失败,且自动修复仍失败,页面会显示原始 IR 和错误列表。此时可在文本框中手工修正 IR,再点击“使用修正后的 IR 渲染”。

## 内网替换 NGA

Mac 开发期默认使用 `backend/app/generators/stub.py` 的确定性 stub。替换点在 `backend/app/generators/interface.py` 的 `default_ir_generator()`。

内网接入时保持 `generate(prompt, *, target)` 签名不变,把默认 generator 换成 NGA adapter。该 adapter 负责通过 `subprocess.run(..., encoding="utf-8", errors="replace")` 调用 `codeagent.exe`,并把 stdout 作为原始 IR 文本返回。Web 层仍继续执行剥壳、Schema 校验、修复、渲染和合规检查,不需要改 IR 契约。

## 当前不做

历史记录、账号登录、多用户、多模型配置、在线协作均不在当前范围内。
