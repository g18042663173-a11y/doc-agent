# 完整骨架抽取

以 skeleton_draft.json 为起点，阅读每页元素、native_inventory.json 和 slot_candidates.json，写出 DeckSkeleton 2.0。保留全部源页和原顺序，保留所有对象绑定。草稿不是已验收骨架。

识别真实标题、眉题、页脚和导航；不能以顶部文字或最大数字替代语义判断。页角色只能来自受控枚举，其他语义使用 ASCII 键，不复制源事实。封面、目录、结束页、图片页均进入清单。

SmartArt 节点使用原生逻辑节点引用，图表使用 sp_ID.chart，表格使用 sp_ID.cell_R_C，共享业务文字使用 part_HASH.sp_ID。图像由清单标记原像素保留，不转换为槽位或空框。无文字的纯图页允许零文本槽。

所有可见原生文字必须绑定或明确列为结构标签。不能因材料不足、识别不准或难处理而省略整个页面。结构标签仅使用受控词表，图像内旧字作为像素保留项单列。

宿主在 seal 前修正角色和语义，seal 检查源页完整性、槽位覆盖和源文边界；源副本留在内部工作目录供全页视觉对照。
